Base URL:
  http://localhost:8081/api/v1

Note:
- All endpoints below are exposed via the API Gateway and map internally to
  the User Login Service and User Config Service.
- You can use these directly in Postman or with curl.

======================================================================
HEALTH CHECK
======================================================================

GET /health

Example (curl):
curl http://localhost:8081/api/v1/health


======================================================================
USER LOGIN SERVICE ENDPOINTS (via API Gateway)
======================================================================

1) REGISTER USER CREDENTIALS
----------------------------------------
Method: POST
Path:   /credentials/register

Description:
Register and store user credentials (API keys, password, TOTP secret, etc.)
for automatic login.

Example (curl):
curl -X POST http://localhost:8081/api/v1/credentials/register \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "IS14415",
    "api_key": "your_jwt_token_here",
    "x_api_key": "your_x_api_key",
    "api_url": "https://jri4df7kaa.execute-api.ap-south-1.amazonaws.com/prod/interactive",
    "totp_secret": "DBUESNYUFRNQMD3Q",
    "source": "MOBILEAPI",
    "preferred_login_type": "PASSWORD",
    "preferred_second_auth": "TOTP",
    "client_id": "IS14415"
  }'


2) LOGIN
----------------------------------------
Method: POST
Path:   /auth/login

Description:
Performs login and creates a user session. If credentials contain a TOTP
secret and auto-generation is enabled, the backend generates the TOTP.

Example (curl):
curl -X POST http://localhost:8081/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "IS14415",
    "login_type": "PASSWORD",
    "password": "Poly@123#",
    "second_auth_type": "TOTP",
    "second_auth": "",
    "source": "MOBILEAPI",
    "udid": "device-uuid-123",
    "version": "2.0.0",
    "device_info": {
      "platform": "web",
      "os": "Windows 10"
    }
  }'


3) VALIDATE SESSION
----------------------------------------
Method: PUT
Path:   /session/validate

Headers:
- X-Session-ID: <session_id>

Description:
Validates if a session is still active and updates last activity.

Example (curl):
curl -X PUT http://localhost:8081/api/v1/session/validate \
  -H "X-Session-ID: your-session-id-here"


4) GET ACTIVE SESSION FOR A USER
----------------------------------------
Method: GET
Path:   /session/user/{user_id}/active

Description:
Retrieve the current active session for the given user.

Example (curl):
curl http://localhost:8081/api/v1/session/user/IS14415/active


5) GET ALL SESSIONS FOR A USER
----------------------------------------
Method: GET
Path:   /session/user/{user_id}/all
Query:  include_inactive=<true|false>

Description:
Get all sessions for a user. Use include_inactive to include closed sessions.

Example (curl):
curl "http://localhost:8081/api/v1/session/user/IS14415/all?include_inactive=false"


6) LOGOUT (SINGLE SESSION)
----------------------------------------
Method: POST
Path:   /auth/logout

Headers:
- X-Session-ID: <session_id>

Description:
Invalidate a single session by session ID.

Example (curl):
curl -X POST http://localhost:8081/api/v1/auth/logout \
  -H "X-Session-ID: your-session-id-here"


7) LOGOUT ALL SESSIONS FOR A USER
----------------------------------------
Method: POST
Path:   /auth/logout-all/{user_id}

Description:
Invalidate all sessions for a particular user.

Example (curl):
curl -X POST http://localhost:8081/api/v1/auth/logout-all/IS14415


8) GET LOGIN HISTORY
----------------------------------------
Method: GET
Path:   /history/{user_id}
Query:  limit=<int>

Description:
Fetch login history for a user.

Example (curl):
curl "http://localhost:8081/api/v1/history/IS14415?limit=50"


9) GENERATE TOTP (UTILITY)
----------------------------------------
Method: POST
Path:   /totp/generate

Description:
Generate a TOTP code from a given secret.

Example (curl):
curl -X POST http://localhost:8081/api/v1/totp/generate \
  -H "Content-Type: application/json" \
  -d '{
    "secret": "DBUESNYUFRNQMD3Q"
  }'


10) AUTH SERVICE STATISTICS (ADMIN)
----------------------------------------
Method: GET
Path:   /admin/stats

Description:
Fetch internal statistics for the authentication service.

Example (curl):
curl http://localhost:8081/api/v1/admin/stats


======================================================================
USER CONFIG SERVICE ENDPOINTS (via API Gateway)
======================================================================

These endpoints proxy to the gRPC-based User Config Service.


1) CREATE STRATEGY
----------------------------------------
Method: POST
Path:   /strategies

Description:
Create a new trading strategy for a user.

Example (curl):
curl -X POST http://localhost:8081/api/v1/strategies \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "IS14415",
    "strategy_name": "High Impact News Trader",
    "description": "Trades on high-impact news with positive sentiment",
    "activate_immediately": true,
    "conditions": {
      "match_all_news": false,
      "impact_score_threshold": 7,
      "sentiments": [1, 2],
      "categories": ["Results", "Board Meeting"],
      "exchanges": [1, 2],
      "price_range": {
        "min": 10.0,
        "max": 1000.0
      },
      "volume_threshold": 100000,
      "pct_change_threshold": 2.0
    },
    "trade_config": {
      "order_type": 1,
      "quantity": 100,
      "exchange": 1,
      "order_side": 1,
      "validity": "DAY",
      "max_position_size": 50000.0,
      "stop_loss_pct": 2.0,
      "take_profit_pct": 5.0
    },
    "risk_limits": {
      "max_daily_trades": 10,
      "max_loss_per_day": 10000.0,
      "position_sizing": 1,
      "max_portfolio_exposure_pct": 25.0,
      "enable_risk_checks": true
    }
  }'


2) LIST USER STRATEGIES
----------------------------------------
Method: GET
Path:   /users/{user_id}/strategies
Query:  active_only=<true|false>, page=<int>, page_size=<int>

Description:
List strategies for a given user with optional filters and pagination.

Examples (curl):

# All strategies
curl http://localhost:8081/api/v1/users/IS14415/strategies

# Active only
curl "http://localhost:8081/api/v1/users/IS14415/strategies?active_only=true"

# With pagination
curl "http://localhost:8081/api/v1/users/IS14415/strategies?page=1&page_size=5"


3) GET STRATEGY BY ID
----------------------------------------
Method: GET
Path:   /strategies/{strategy_id}
Query:  user_id={user_id}

Description:
Get details for a specific strategy.

Example (curl):
curl "http://localhost:8081/api/v1/strategies/{strategy_id}?user_id=IS14415"


4) UPDATE STRATEGY
----------------------------------------
Method: PUT
Path:   /strategies/{strategy_id}

Description:
Update an existing strategy. Version is used for optimistic locking.

Example (curl — full update):
curl -X PUT http://localhost:8081/api/v1/strategies/{strategy_id} \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "IS14415",
    "strategy_name": "Updated Strategy Name",
    "description": "Updated description",
    "version": 1
  }'


5) ACTIVATE STRATEGY
----------------------------------------
Method: POST
Path:   /strategies/{strategy_id}/activate

Description:
Activate a strategy so it becomes eligible for rule matching.

Example (curl):
curl -X POST http://localhost:8081/api/v1/strategies/{strategy_id}/activate \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "IS14415"
  }'


6) DEACTIVATE STRATEGY
----------------------------------------
Method: POST
Path:   /strategies/{strategy_id}/deactivate

Description:
Deactivate a strategy so it stops participating in rule matching.

Example (curl):
curl -X POST http://localhost:8081/api/v1/strategies/{strategy_id}/deactivate \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "IS14415"
  }'


7) DELETE STRATEGY
----------------------------------------
Method: DELETE
Path:   /strategies/{strategy_id}
Query:  user_id={user_id}

Description:
Delete a strategy for a user.

Example (curl):
curl -X DELETE "http://localhost:8081/api/v1/strategies/{strategy_id}?user_id=IS14415"
